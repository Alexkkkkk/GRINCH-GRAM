### Фикс center-below skipped_ai (68a316f)

**Проблема 1 (SELL loop):** Когда цена поднималась до sell-уровня, созданного из
BUY-цикла ниже центра — уровень помечался `skipped_ai` вместо исполнения.
Код: `if level.price_ton <= center: level.status = 'skipped_ai'` — удалён.
Profit-guard (`_is_profitable_sell`) теперь сам решает — он корректно использует
`level.amount_ton` как базу затрат для BUY-циклов.

**Проблема 2 (Restore loop):** `skipped_ai` уровни ниже центра никогда не
восстанавливались — `if _lv.price_ton <= center: continue` блокировало их.
Условие удалено — теперь все skipped_ai проходят нормальную оценку.

**Проблема 3 (Display):** `next_pct_away` вычислялся от центра, а не от текущей цены.
Исправлено: `get_status()` теперь получает `_cur_price` через `price_feed.get_grinch_ton_price()`.

**Результат:** Сразу после перезапуска SELL L125 выполнился: +2.646 TON прибыли.
