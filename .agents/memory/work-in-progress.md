## ⚠️ Важно про деплой на VPS

- **Статика НЕ монтируется как volume** — только `/app/data` в docker-compose
- `docker cp` работает пока контейнер не пересоздаётся (`docker compose up --build`)
- Правильный деплой: scp → /opt/bot/ → `docker compose up -d --build`
- Или: scp → docker cp (для hotfix без rebuild, живёт до следующего rebuild)
