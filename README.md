Quick Start ### Prerequisites - Python 3.11+ - PostgreSQL 14+ - Docker (optional) ### Local Development ```bash git clone https://github.com/Alexkkkkk/GRINCH-GRAM.git cd GRINCH-GRAM python -m venv .venv && source .venv/bin/activate pip install -r requirements.txt cp .env.example .env # Edit .env with your API keys python app.py # Open http://localhost:5000 ``` ### Docker (One Command) ```bash docker compose up -d # Open http://localhost:5000 ``` ### Production Deploy ```bash # After configuring GitHub Secrets gh workflow run vps-deploy.yml ``` --- ##
